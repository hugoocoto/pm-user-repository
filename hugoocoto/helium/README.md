# Helium

Third-party desktop client for the [Imput](https://imput.com) browser. Pre-built tarball (always the latest release), unpacked to `~/.local/share/pm/opt/`. Upstream source at [imputnet/helium-linux](https://github.com/imputnet/helium-linux).

**Tech stack:** Chromium-based (pre-built binary). The tarball is used instead of the AppImage because the AppImage's FUSE mount makes startup ~4s slower.

**Type:** GUI desktop application.

## Use

```
helium
```
