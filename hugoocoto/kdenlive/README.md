# Kdenlive

Non-linear video editor from KDE, built on the MLT framework. Official x86_64 AppImage, always the latest release (resolved from download.kde.org). Upstream at [kdenlive.org](https://kdenlive.org).

**Tech stack:** Qt/KDE Frameworks (pre-built AppImage, needs FUSE).

**Type:** GUI desktop application.

## Use

```
kdenlive
```
