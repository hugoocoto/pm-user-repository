# Kdenlive

Non-linear video editor from KDE, built on the MLT framework. Official x86_64 AppImage, pinned to 26.08.1. Upstream at [kdenlive.org](https://kdenlive.org).

**Tech stack:** Qt/KDE Frameworks (pre-built AppImage, needs FUSE).

**Type:** GUI desktop application.

## Use

```
kdenlive
```
